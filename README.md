# Multi-Agent Personal Assistant Swarm

## Overview

An intelligent collaborative AI system that uses multiple specialized
AI agents to decompose, execute, validate, and complete complex user tasks.

## Project Type

B.Tech Final Year Project

## Domain

Artificial Intelligence & Data Science

## Main Objective

To develop an intelligent personal assistant that can understand complex
user requests, divide them into subtasks, delegate those tasks to
specialized AI agents, use external tools, maintain contextual memory,
validate results, and generate a unified response.

## Planned AI Agents

- Supervisor Agent
- Research Agent
- Planning Agent
- Analysis Agent
- Writing Agent
- Memory Agent
- Tool Agent
- Validator Agent

## Technology Stack

- Python
- Gemini API
- LangGraph
- LangChain
- Streamlit
- ChromaDB
- SQLite
